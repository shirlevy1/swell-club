## הרצה

```bash
npm install
npm run dev
```

### מצב הדגמה (ברירת מחדל)

**בלי קובץ `.env.local` האפליקציה עולה במצב הדגמה** — בלי מסד נתונים,
בלי הרשמה ובלי התחברות. נועד להראות איך המוצר עובד.

מה יש בו: קהילה של 9 אנשים, ארבעה מפגשים, ואפשר באמת ללחוץ מסביב.

מה כדאי להראות, לפי הסדר:

1. **מפגש שהיה, שלא נכחתם בו** (״זריחה בחוף״) — הרשימה נעולה. זה כל
   הרעיון במשפט אחד
2. **מפגש שכן נכחתם בו** (״שחייה ארוכה״) — הרשימה נפתחת, עם סלפי, שם,
   וואטסאפ ואינסטגרם
3. **המפגש הפתוח עכשיו** — לחיצה על ״הגעתי״ פותחת מצלמה אמיתית. הסלפי
   שתצלמו נכנס לרשימה מיד
4. **ניהול** — הפער בין כמה סימנו שיגיעו לכמה הגיעו בפועל

⚠️ בהדגמה מדולגת בדיקת המיקום — אין חוף ואין GPS. באמת, בלי להיות
במקום, הכפתור לא עובד.

⚠️ המצלמה עובדת רק דרך `localhost` או HTTPS. אם פותחים את ההדגמה
מהטלפון דרך כתובת IP ברשת המקומית, שלב הסלפי ייכשל — זו מגבלת דפדפן,
לא באג.

הנתונים חיים בזיכרון התהליך. עצירה של השרת מאפסת הכל.

### מצב אמיתי

עם `.env.local` שמכיל מפתחות Supabase, אותה אפליקציה עוברת אוטומטית
למצב מלא — הרשמה, התחברות, מסד נתונים ואחסון. ראו [SETUP.md](SETUP.md).
